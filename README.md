# Android Club Showcase

A responsive, single-page Android Club showcase built with vanilla HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static-file server.

## Features

- Android-inspired boot sequence, phone UI hero, theme switcher, scroll reveal and progress indicator
- About, Projects (with filters/detail dialog), Events (upcoming/past tabs and countdown), Join, Contact and footer
- Responsive layout with a dedicated mobile bottom navigation
- Original vector/CSS visuals and clearly marked placeholder contact details

## Content

Projects, event details and placeholder content are embedded in `app.js` for this small static implementation. Replace the arrays near the top of that file to update them.
